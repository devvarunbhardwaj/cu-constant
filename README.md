# cu-constant

Machine-written content for [CU-LKN](https://github.com/Aryanzutshi/CU-LKN).

Every file here except this one is generated by the **Website** panel in the CU
Strapi admin and committed by it. Nothing in this repository is edited by hand —
the next publish overwrites it.

- `<section>.ts` — the values
- `types/<section>.d.ts` — the shapes
- `types/media.d.ts` — the shared `CmsImage`
- `index.ts` — re-exports every section
- `manifest.json` — what the last publish wrote, and when

To change what is in here, edit the content in Strapi and press
**Publish to website**.
